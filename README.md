# CYBER_PUZZLE.AI

A real-time AI hand-gesture controlled sliding puzzle game. Built directly into the browser. 

## Features
- **Zero Dependencies Backend:** Everything runs locally using HTML5 Canvas API and JavaScript.
- **MediaPipe Integrations:** Leverages Google's fast in-browser machine learning for real-time skeletal hand tracking.
- **Gesture Control System:** Pinch to capture webcam frames. Drag and drop to slide the generated puzzle pieces securely.
- **Cyberpunk UI:** Modern glassmorphism panels, CSS3 glow effects, logic-controlled background particle generation.

## How to Play
1. Launch `index.html` in your favorite modern browser (e.g., via VS Code Live Server or by double clicking).
2. Allow webcam permissions when prompted.
3. Bring your thumb tip and index finger tip together (Pinch) for 0.4 seconds to Capture your photo.
4. The snapshot transforms into a randomized and guaranteed solvable 3x3 grid puzzle.
5. Pinch on tiles adjacent to the empty square and drag your hand to shift them until the picture is restored!
